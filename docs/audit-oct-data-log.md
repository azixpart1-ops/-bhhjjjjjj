### Rules used

- **core_type**: from the summary paragraph and "What they get" bullets, ignoring sentences that point to other beds ("see our memory foam beds"): crumb memory foam > memory foam > egg-crate > mesh > fibre. Plain "foam", "filled" or "cushioned" gives blank.
- **foam_guarantee**: true when the description states the "5-year no-flatten guarantee" (all 23 also say memory foam and are the 23 Appendix A "Yes" beds). Never written false.
- **has_liner**: a waterproof inner liner, lining, layer, membrane or film stated in the summary or bullets. A waterproof outer fabric is not a liner.
- **non_slip**: "non-slip", "anti-slip" or "non-skid" base or feet, ignoring "X or Y?" comparison paragraphs about other beds.
- **wash_temp**: a stated "NN°C". Only 30 appears.
- **cover_type**: coated / wipe-clean outer gives "Coated, wipe clean"; otherwise a removable, zipped, unzipping, "comes off" or unclipping cover gives "Zip-off fabric" (the task's mapping for any removable washable cover); otherwise blank. Not set on kennels, day beds or steps. "Fixed cover" was never stated, so it is unused.
- **low_entry**: only the PDF list (Coniston, Newlands, Easedale, Burnmoor, Braithwaite), each confirmed by its own wording (quoted below).
- **ships_from**: tag "Shopify Collective" gives "Partner warehouse", otherwise "Own stock". **dispatch_days_min/max**, **density_kg_m3**, **entry_height_cm**: no description states them, all blank. **ships_same_day**: never set.
- **shape**: title / product type / tags first, then the description. **sleep_style**: PDF mapping (curlers to nests and all-round bolsters, head-on-the-edge to bolsters and raised edges, stretchers to mattresses and flat beds) plus the bed's own wording; blank for kennels, day beds, steps, car seat.
- **foam_depth**: only where the description says the foam itself is N cm (not the bed's outside depth). **sleep_area**: only where the description gives a sleeping area, or says the whole surface is usable. **suits_weight**: only stated per-size weight limits, mapped to the band containing the limit.
- **subtitle** (max 70 characters, one per bed, none shared) and **best_for**: written for every product from its own description, adapted from the PDF's subtitles by bed type; automated checks: no em dash, no "memory foam" on a non-memory-foam bed, no "egg-crate", "fibre", "30°C" or "liner" unless that bed's data says so, no medical words.
- **feel**, **worth_it**, **qa**: Coniston only (the PDF gives no text or firmness for other beds).
